Your Referral Tokens Never Arrived? The 48-Hour Redemption Trap

The 1-billion-token invite bonus is the most talked-about Muse offer online — and the easiest one to lose. Joining isn't redeeming, the clock starts the moment you sign up, and each account gets one shot.

By Marvin Jones

Last checked against the live product: September 26, 2026.

The invite program is simple on paper: enter a friend's invite code in Settings within 48 hours of creating your Muse account, and you both get 1 billion Muse tokens. No purchase, no card, no fine print that bites. It became the launch's most viral mechanic for a reason — a billion tokens is a giant buffer of free usage on top of your normal weekly allowance.

It's also the #1 source of complaints, because the offer has four quiet failure modes. Here's each one, and how to dodge it.

Trap 1: Joining isn't redeeming

This is the big one. Tapping a friend's muse.ai/join link gets you an account — it does not apply their code. The code is entered in a separate step, in Settings: Settings → General → Redeem Invite Code on the web, or Settings → Redeem invite code in the app. (The exact path can vary slightly by platform — look for the redeem control, not the invite link. The join URL does not embed the code.)

Plenty of people complete signup, assume the code they clicked through with was counted, and never open Settings. Those tokens are gone. The step-by-step walkthrough lives in the invite-code guide.

Trap 2: The 48-hour clock starts at signup

The window isn't "48 hours from when you find a code" — it's 48 hours from when you created the account. Join on a Tuesday morning, find a code on Thursday afternoon, and you're out of luck. Reviewers who've tested the flow say the code field won't save you after the window closes, and Meta's stated terms tie the bonus to that window.

Field note

Redeem the code in the same sitting as signup. It's a five-minute task — the people who lose the bonus are the ones who bookmark it for later.

Trap 3: One account, one redemption

Each account can redeem exactly one invite code. If you've already redeemed one — or if you joined weeks ago and the window lapsed — there's no second chance on that account. You can't stack two friends' codes on one account.

Trap 4: The code itself can run out

Invite codes have limited lives. Community reports put the cap at 20–30 redemptions per code, and some referral trackers report Meta also caps each user at around 20 invites shared. Meta hasn't published either number in a public doc, so treat them as community-reported — but the practical lesson is solid: codes posted publicly get exhausted fast. If a code fails, try a fresher one before assuming the system is broken.

What the billion tokens are actually worth

A billion tokens sounds abstract. The free tier ships roughly 100 million tokens a week, so the bonus works out to about ten free weeks of normal use — that "ten weeks" figure is a growth blog's estimate, not Meta's number, and your mileage depends on how much you hand the agent.

Two details worth knowing:

  • The bonus sits in your balance separately from the weekly allowance. Once the week's free tokens run out, Muse starts drawing on the bonus.
  • Reviewers citing the in-app terms report the bonus tokens don't expire. The public offer pages don't state an expiry either way, so confirm in your own Usage tab rather than taking anyone's word for it.
Caution

The offer can change or end. Meta's terms live inside the app, not in a press release — check what your account shows before assuming the deal is still what a two-week-old YouTube video said it was.

How to check it landed

After redeeming, open the usage/token-balance area in Settings and confirm the bonus balance is there. If it isn't, the most likely explanations are: the 48-hour window had already closed, the code had hit its use cap, or that account had already redeemed a code.

What to watch

The invite program is still the #1 Muse topic online, which means the details keep shifting: published use-caps, a per-user invite ceiling, whether Meta formalizes any of the community-reported numbers. I'll update this page when the official terms change.

Quick answers

How do I redeem a Muse invite code?

Join Muse first, then go to Settings → General → Redeem Invite Code (web) or Settings → Redeem invite code (app) and enter the code — within 48 hours of creating your account.

I joined with a code but never got tokens. What happened?

The most likely causes: you joined but never redeemed the code in Settings (joining ≠ redeeming), the 48-hour window closed, the code hit its use cap, or the account already redeemed a code.

How many tokens does the referral give?

1 billion tokens to you and 1 billion to the person whose code you redeemed.

Do the bonus tokens expire?

Reviewers citing the in-app terms say they don't expire — but the public offer pages are silent on expiry, so confirm in your own Usage tab.

Can I redeem more than one code?

No — one redemption per account.

How many times can my own code be used?

Community reports say 20–30 redemptions per code. Meta hasn't published the number.

Where do I find my own invite code to share?

Look for the Invite button — reviewers report it at the top-right of the main chat screen — or the invite/referral section in Settings.

Can I use a referral code after the 48-hour window?

You can try entering it, but Meta's stated terms tie the bonus to redemption within 48 hours of joining, so a late redemption isn't guaranteed to pay out.

Is the referral program available in my country?

The referral terms track Muse's own availability — currently the US, Canada, and Mexico, per Meta. Check that Muse is available to you before counting on a code.
