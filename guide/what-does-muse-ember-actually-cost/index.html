What Does Muse Ember Actually Cost? Settling the $0.10, $0.30 and $0.50 Pricing Fight on a Primary Page

Meta's own pricing page settles the Ember fight. The base price is $0.10 per million input tokens and $0.50 per million output tokens, and the $0.30 figure is not a rival base price. It is the long-context input rate that applies once a request passes 200,000 input tokens, at which point the whole request bills at triple rates. No source checked on November 16 supports a 20,000 token threshold or a $1.20 output price.

By Marvin Jones

Last checked against the live product: November 16, 2026.

Price Check: Muse Ember

Price Check: Muse Ember

A standing box for the Ember price, placed here so the dated answer sits next to the headline. Last updated November 16, 2026, from Meta's Model API pricing page, read in full that day, and the provider listings listed in Sources.

  • Input price, checked November 16, 2026 on a primary: $0.10 per million input tokens for a request with up to 200,000 input tokens. Cached input is $0.004 per million. Source: Meta, dev.meta.ai/docs/pricing-rate-limits, model muse-ember-1.0, Standard mode.
  • Output price, checked November 16, 2026 on a primary: $0.50 per million output tokens at the same tier. No primary or provider page checked that day supports $1.20 as an output price.
  • Tier threshold, checked November 16, 2026 on a primary: 200,000 input tokens, not 20,000. Past that line the rates triple to $0.30 input, $0.012 cached input, and $1.50 output per million, and the higher rates apply to the whole request, not only to the tokens past 200,000.
  • Promise Ledger rows still open, recheck dated November 23, 2026: whether OpenRouter and Vercel charge the long-context tier their pages do not display, why Poe lists output at $0.51 instead of $0.50, and whether Oracle publishes a per-token Ember price in its own name. The launch claim this ledger opened with, $0.10 per million input tokens on November 9, is confirmed at base tier and incomplete as a full price, because it omits the tier.

What Meta's pricing page actually says

The page is titled "Pricing and rate limits" on Meta's developer site, and it gives Ember one row set with two columns. The first column covers a request with up to 200K input tokens: input $0.10 per million, cached input $0.004 per million, output $0.50 per million. The second column covers a request with more than 200K input tokens: input $0.30 per million, cached input $0.012 per million, output $1.50 per million. Every rate in the second column is exactly three times the first. The model name on the page is muse-ember-1.0, and the page notes that Contributor mode is not available for Muse Ember, Standard mode only.

Two details in Meta's wording change how a bill actually lands, and both are easy to miss in a snippet. First, the input tokens in a request set the tier, cached tokens included. A request does not stay cheap because most of its prompt came from cache: the cached tokens still count toward the 200,000 line, even though they bill at the cached rate. Second, when a request continues a stored conversation through previous_response_id, its input includes that conversation. A chat that grows turn by turn can cross into the long-context tier on accumulated history, not on anything new the user typed.

The sharpest sentence on the page is the billing rule for the crossing itself. A request with more than 200K input tokens is billed at the long-context rates in full, not only for the tokens past 200K. There is no blended bill, part at the base rate and part at the higher one. One token over the line reprices the entire request.

Meta's page also lists Ember rate limits, 3,000 requests per minute and 4,000,000 tokens per minute, and a web search grounding price of $2.50 per 1,000 search queries. The page shows no date. The model release date, November 9, 2026, comes from the provider listings below.

The arithmetic of one token over

Run the numbers on Meta's rates and the cliff is visible in cents. A request with 200,000 input tokens and 10,000 output tokens costs $0.020 in input and $0.005 in output, $0.025 in total. Add 1,000 input tokens, taking the request to 201,000, and the whole request moves tier: input costs $0.0603 at the $0.30 rate, output costs $0.015 at the $1.50 rate, $0.0753 in total. The extra 1,000 tokens tripled the bill.

That worked example uses list rates only, with no cached input, because cache changes the per-token charge without changing the tier rule. A mostly cached 201,000 token request pays the cached rate on the cached share, at the long-context cached price of $0.012 per million. It does not return to the base tier. Cache lowers the rate. It does not lower the tier.

Field note

The snippet fight makes sense once the tier is on the page. A page that quotes the long-context column reads as $0.30 input. A page that quotes the base column reads as $0.10 input and $0.50 output. Both pages can be copying real numbers and still disagree, because neither snippet said which column it took. The $0.30 against $0.50 argument that ran through this site's November 14 to 16 sweeps was two columns of one table being read as two competing prices.

Which snippet figures no primary supports

Two figures in circulation get no support from any full read run on November 16, 2026, and this post names them so they stop travelling.

The 20,000 token threshold appears in repeated November 16 snippets in this site's demand-log sweeps. No full page read that day contains it: not Meta's pricing page, not OpenRouter, not Vercel, not Poe, and not the Zeniteq secondary that first printed the tier. Every tier reference in a full read is 200,000 tokens. Twenty thousand reads like a dropped zero that copied well.

The $1.20 output figure comes from an OpenRouter snippet dated November 14 in this site's record. OpenRouter's own page, read in full on November 16, lists output at $0.50 per million from both of its Ember providers. No page read in full that day lists $1.20 for Ember output at any tier: the long-context output rate on Meta's page is $1.50, and the base rate is $0.50. A figure can sit between two real figures and still be supported by neither.

The provider listings, printed separately

Providers do not all show the same price page, and merging them into one Ember price would hide the two findings in this section: no provider page checked displays the long-context tier, and one provider charges a cent more for output.

OpenRouter, read in full on November 16, 2026, lists Muse Ember at a November 9, 2026 release with a 1.0M token context. It names two providers, Meta and Google Vertex, and both list the same rates: input $0.10 per million, output $0.50 per million, cache read $0.004 per million. The page also shows a weighted average actually paid, lower on input at $0.02259 per million, which reflects cached traffic in the mix rather than a different list price. A search of the page for the tier found no match: OpenRouter's page shows no 200,000 token threshold and no long-context rates. Whether a long request through OpenRouter bills at Meta's triple rates is not stated on the page. That is an open ledger row above, with a recheck date, not a gap this post fills by guessing.

Vercel AI Gateway, read in full on November 16, lists input $0.10, output $0.50, and cache read $0.004 per million, with Meta as the only provider in its table, a 1M context, and a release date of November 9, 2026. Its page also shows no long-context tier. Netlify's changelog of November 9, 2026, read in full the same day, confirms Ember 1.0 live in its AI Gateway alongside Muse Spark and Muse Wonder, and lists no per-token price at all. A developer comparing gateways on price pages alone would see one price everywhere and no tier anywhere, which is a different picture from Meta's own page.

Poe is the outlier. Poe's Muse Ember page was read in full on November 16, with its rates view opened. It prices input at $0.10 per million tokens and text output at $0.51 per million tokens. The charge is in points: 4 points per 1,000 input tokens and 17 points per 1,000 output tokens. The output figure is $0.51, not the $0.50 every other listing shows. Poe states a 96 percent discount on cached chat and gives no dollar cached rate. Poe shows no tier either, and its message cost varies by length. One cent per million output tokens will not change many bills. It still belongs in print. A reader who checks Poe against this post will find the difference, and this site does not have an explanation for it yet. Poe may round its points conversion up, or price output on its own margin. Poe's page does not say which.

Caution

Oracle has no Ember pricing page in this check. Meta's November 9 post, read in full for this site on November 10, says Ember, Spark and Wonder are available on Google Cloud and Oracle Cloud. A DuckDuckGo search for an Oracle Ember price on November 16 returned no Oracle pricing page and no Oracle per-token figure, only a snippet from a secondary roundup naming Oracle Cloud and Google Cloud as hosts. Oracle's own pretrained models page, checked November 10 for this site, listed no Muse model. Availability stated by Meta and a price published by Oracle are two different records, and only the first one exists today. Cloudflare is in the same position in this run. An earlier site check on November 10 read a Cloudflare Ember model page at $0.10 and $0.50. The November 16 search returned no Cloudflare listing to re-read. That figure stands at its November 10 date and is not refreshed here.

What the Artificial Analysis number is, and is not

Artificial Analysis, in its article of November 9, 2026, read in full for this site's November 11 post, scored Ember 36 on its Intelligence Index and put its cost at $0.14 per task, using $0.10 and $0.50 per million input and output tokens. That $0.14 is a measured cost per finished task at max reasoning. It is not a per-token price, and it settles nothing about the tier, because a per-task average can sit under the base rates while individual long requests bill at triple. Readers who saw $0.14 quoted as evidence that Ember is simply cheap were reading a different measurement. This post is only about the per-token price and its tier, which is the bill a developer can predict before running anything.

The September 2026 baseline research this site works from predates Ember entirely, so it offers no help on this price. Every figure above comes from a page read in full on November 16, 2026, or from an earlier full read dated where it is used.

What Ember pricing is not

Ember is a developer model, sold by the token on Muse Code and the Meta Model API. Its price is not the Muse subscription. The consumer plans this site covers in its pricing guide, Free, Power at $20 a month, and Maximum at $100 a month, are a separate record, and nothing on Meta's Ember pricing page changes them. No consumer Muse app rollout for Ember was stated in the November 9 announcement, and none is stated on the pricing page read November 16.

Three standing records hold flat beside this settlement. Muse calling businesses is paid and US only on this site's November 14 record. Poppy is Sierra's third-party protocol, not a Meta model, and its November 15 post changes nothing about Ember's price. Expedia in Muse is still hotels only, with flights not verified. A settled Ember price moves none of those rows.

Quick answers

What does Muse Ember cost?

On Meta's own pricing page, read November 16, 2026: $0.10 per million input tokens, $0.004 per million cached input tokens, and $0.50 per million output tokens, for a request with up to 200,000 input tokens.

What is the $0.30 Ember price in some listings?

It is Meta's long-context input rate, not a second base price. Past 200,000 input tokens in a request, input rises to $0.30 per million, cached input to $0.012, and output to $1.50, and the higher rates apply to the whole request.

Is the tier threshold 20,000 or 200,000 tokens?

200,000, on Meta's pricing page. No page read in full on November 16, 2026 contains a 20,000 token threshold for Ember. Every full-read tier reference is 200,000.

Is Ember output $1.20 per million anywhere?

No source checked in full on November 16 supports $1.20. Meta lists output at $0.50 base and $1.50 long-context. OpenRouter and Vercel list $0.50. Poe lists $0.51. The $1.20 figure rests on a November 14 snippet that OpenRouter's own page does not back.

Do OpenRouter and Vercel charge the long-context tier?

Their pages do not say. Both list only the base rates, $0.10 input and $0.50 output per million, with no tier shown, in full reads on November 16, 2026. This site rechecks on November 23, 2026.

Why does Poe charge $0.51 for output?

Poe's page states the figure, in points, and gives no reason. It is one cent above the $0.50 on Meta, OpenRouter, and Vercel. This site has no Poe statement explaining the difference.

Frequently Asked Questions

Q: Is Ember priced per token or per task?

A: Per token, on Meta's pricing page: input, cached input, and output are each priced per million tokens, in two tiers set by the input size of the request. The $0.14 per task figure in coverage is Artificial Analysis's measured average cost per finished task from its November 9, 2026 article. It is a test result, not a price Meta charges.

Q: Do cached tokens push a request into the higher tier?

A: Yes, on Meta's wording. The input tokens in a request set the tier, cached tokens included. Cached tokens bill at the cached rate, $0.004 per million at base tier and $0.012 in the long-context tier, but they count toward the 200,000 token line.

Q: If my request is 1,000 tokens over the line, do I pay the higher rate only on those 1,000?

A: No. Meta's page states that a request over 200K input tokens is billed at the long-context rates in full, not only for the tokens past 200K. The worked example in this post shows a 201,000 token request costing about three times the same request at 200,000 tokens, on list rates with no cache.

Q: Does a long conversation cross the tier by itself?

A: It can, on Meta's page. When a request continues a stored conversation through previous_response_id, its input includes that conversation. The accumulated history counts as input for tier purposes, so a growing conversation can cross 200,000 input tokens without a single long message.

Q: Is Ember available on Oracle Cloud, and what does Oracle charge?

A: Meta's November 9, 2026 post says Ember, Spark and Wonder are available on Google Cloud and Oracle Cloud. No Oracle Ember pricing page or per-token figure was found in the November 16, 2026 checks, and Oracle's own pretrained models page listed no Muse model when this site checked it on November 10. The availability claim is Meta's. An Oracle price, in Oracle's name, does not exist in this record yet.

Q: Does Ember's price change the Muse subscription plans?

A: No connection is stated anywhere checked. Ember is priced per token for developers on Muse Code and the Meta Model API. Muse subscriptions for the personal agent, Free, Power at $20 a month, and Maximum at $100 a month, sit in a separate pricing record that this site's pricing guide covers, last checked September 18, 2026 in that guide.
