Do OpenRouter and Vercel Charge Ember's Long-Context Tier? The November 23 Recheck, With Poe's Extra Cent and Oracle's Missing Price

Meta's own pricing page says Ember triples past 200,000 input tokens, to $0.30 input and $1.50 output per million, applied to the whole request. OpenRouter and Vercel, both re-read in full on November 22, 2026, still list only the base $0.10 and $0.50 rates with no long-context tier stated. Poe still lists output at $0.51. Oracle still publishes no Ember price in its own name.

By Marvin Jones

Last checked against the live product: November 22, 2026.

Verdict first: do not assume a gateway bill follows Meta's tier, and do not assume it ignores the tier either. On November 22, 2026, OpenRouter and Vercel AI Gateway each listed Ember at $0.10 input and $0.50 output per million tokens, with $0.004 for cache read, and neither page stated a rate past 200,000 input tokens. Meta's own page states that rate in full. Until a gateway prints its long-context rate or a reader produces a bill over that line, the gateway charge past 200,000 tokens is unstated, not settled. This site rechecks all four provider rows on December 7, 2026.

Promise Ledger

The November 17 post on this site, What Does Muse Ember Actually Cost, settled the base price and left three rows open with a printed recheck date of November 23, 2026. This post is that recheck, published on the promised date.

  • Row 1, OpenRouter and Vercel long-context billing: still open. Both pages were re-read in full on November 22, 2026. Neither states a long-context tier. New recheck date: December 7, 2026.
  • Row 2, Poe output at $0.51: still open, unchanged. Poe re-read on November 22, 2026 still lists text output at $0.51 per million, one cent above Meta, OpenRouter, and Vercel, with no reason given on the page. New recheck date: December 7, 2026.
  • Row 3, Oracle Ember price: still open, still missing. No Ember pricing page in Oracle's own name was found on November 22, 2026, and Oracle's own pretrained models list, updated November 11, 2026, contains no Muse model at all. New recheck date: December 7, 2026.

A promise kept on date is not the same as a question answered. All three rows stay open, and each one now carries its next date in print.

What Meta itself charges, restated from Meta's own page

Meta's pricing page at dev.meta.ai, re-read on November 22, 2026, gives Ember two tiers, and the input tokens in a request set the tier, cached tokens included.

Up to 200,000 input tokens, per million tokens: cached input $0.004, input $0.10, output $0.50.

Over 200,000 input tokens, per million tokens: cached input $0.012, input $0.30, output $1.50.

Two details on that page change how a bill should be read. First, a request over the line is billed at the long-context rates in full, not only for the tokens past 200,000. Second, when a request continues a stored conversation, its input includes that conversation. A short reply late in a long stored conversation can therefore sit in the higher tier even though the new text is brief. Meta says the invoice and the usage dashboard list the two tiers separately.

Meta also states the contrast with its larger models in the same place: no long-context premium applies to Muse Wonder and Muse Spark. The tier is an Ember rule, not a family rule.

This post does not reopen the base price. The November 17 settlement stands: $0.10 and $0.50 at the base tier, from Meta's own page.

OpenRouter, re-read November 22, 2026

OpenRouter's listing at openrouter.ai/meta/muse-ember shows, in its header, input and output at $0.10 and $0.50 per million, with a 1.0M context figure. Its frequently asked questions section repeats the same pair and adds cache read at $0.004 per million.

The providers table on that page has two rows, Google Vertex and Meta, and both rows show the same three figures: $0.10 input, $0.50 output, $0.004 cache read, per million.

No long-context tier appears on the page. A search of the page text for 200K returned nothing, and the only use of the words long-context on the page is a benchmark label, Medical long-context reasoning, which is a test name, not a price. The page also prints weighted average effective prices, $0.02378 input and $0.4998 output per million, which reflect caching in actual traffic. Those averages are not a tier schedule, and this post does not use them as one.

Result for this row: OpenRouter states the base rate only. Whether OpenRouter bills Meta's triple rate on a request over 200,000 input tokens is not stated on its listing on November 22, 2026.

Vercel AI Gateway, re-read November 22, 2026

Vercel's model page, at vercel.com/ai-gateway/models/meta/muse-ember, lists input at $0.10 and output at $0.50 per million tokens, with cache read at $0.004 per million in its providers table. The Meta row in that table shows a 1M context figure and a release date of November 9, 2026. The page describes a 1,048,576-token context window and implicit prompt caching.

No long-context tier appears on the page. Searches of the page text for 200K and for long-context returned nothing. A 1M context window tells a reader how much a request can hold. It says nothing about what the gateway charges when a request passes 200,000 input tokens, and Vercel's page, on November 22, 2026, does not fill that gap.

Result for this row: Vercel states the base rate only. Its long-context charge is not stated.

Field note

The gap in both listings cuts in two directions, and readers should hold both. A gateway that passes Meta's cost through would need the triple rate somewhere in its billing, even if its model page omits it. A gateway that absorbs or averages the cost would bill the base rate and lose money on long requests, or recover the cost elsewhere. Neither page, read in full, says which arrangement applies. A model page is a price list, not a contract, and the missing tier could live in terms, in a dashboard, or in an invoice line. That is why the reader question at the end of this post asks for bills, not impressions: one invoice for a request over 200,000 tokens, from either gateway, settles more than another re-read of these two pages will.

Poe, re-read November 22, 2026

Poe's page at poe.com/Muse-Ember describes Ember as a multimodal model with a 1M-token context window, powered by a server managed by @meta. Its rates view lists input at $0.10 per million tokens, at 4 points per 1,000 tokens, and text output at $0.51 per million tokens, at 17 points per 1,000 tokens. Cached chat carries a 96 percent discount, stated as a percentage, not as a dollar rate.

The $0.51 figure is unchanged from November 16, 2026, when this site first banked it. It remains one cent above the output rate on Meta's page, on OpenRouter, and on Vercel. Poe's page gives no reason for the difference. It could be rounding inside a points system, a margin, or an error that has survived a week. Poe states none of those, so this post prints none of those. The figure is $0.51, the gap is one cent, and the explanation is still missing.

No long-context tier appears on Poe's page or in its rates view either. Poe is a consumer chat surface priced in points, not a developer gateway, so its silence on the tier has a different weight from the OpenRouter and Vercel silence. It is recorded here because the November 17 post left Poe's cent open, not because Poe was expected to publish a developer tier schedule.

Oracle, checked November 22, 2026

No Ember price from Oracle was found, and the check was wider than a single search.

DuckDuckGo searches for Oracle Muse Ember pricing, for the same terms restricted to oracle.com, and for Oracle Generative AI with Ember pricing produced no Oracle Ember pricing page. The Oracle results that did surface were a generic cost calculation page and a generic cost estimator, neither of which mentions Muse Ember.

Oracle's own document titled Offered Pretrained Foundation Models in Generative AI, updated November 11, 2026, was read directly. A search of its text for Muse returned nothing. Its Meta Models section lists Meta Llama 4 Maverick, Meta Llama 4 Scout, and Meta Llama 3.3 (70B). No Muse Ember, Muse Spark, or Muse Wonder appears in that list, and no Ember price appears anywhere in the document.

A separate Oracle cost document, also updated November 11, 2026, contains no model-specific prices and no Muse mention. It describes on-demand inferencing priced by character length and dedicated clusters priced by committed hours, with detail pushed to a generic pricing page.

Caution

A third-party snippet found during the November 22 searches claimed that Ember, Spark, and Wonder are available on Oracle Cloud. That claim was not verified on any Oracle page, and Oracle's own pretrained models list, updated November 11, 2026, points the other way. This post does not treat a snippet about Oracle as an Oracle price, an Oracle listing, or an Oracle launch. If Oracle publishes Ember, the evidence this site will print is an Oracle page that names Ember and states a price, or a dated Oracle announcement that names it.

Result for this row: Oracle has published no Ember price that this site could find on November 22, 2026, despite the November 9 availability reporting that put Oracle in the launch-day distribution story. The absence is the finding, stated at its exact width: no price in Oracle's own name, in the pages checked, on that date.

What this changes for someone choosing a route today

If your Ember work stays under 200,000 input tokens per request, the four-way comparison is simple on the printed record: Meta, OpenRouter, and Vercel all state $0.10 input and $0.50 output per million, and Poe states $0.10 and $0.51 inside a points system. Price alone gives no reason to pick one gateway over another at that size.

If your work crosses 200,000 input tokens, the printed record stops helping. Meta direct is the only route in this check with a stated long-context price: $0.30 and $1.50 per million for the whole request. On OpenRouter and Vercel, a budget built on the base rate rests on an unstated assumption. Before a large run, send one test request over the line on the gateway you plan to use. Read the charge. Then run the full job. That test costs one long request. Skipping it risks a bill at three times the planned rate across the entire request, because Meta's tier, if passed through, applies in full, not just past the line.

Records this post does not change

Consumer Muse pricing still stands at free, Power at $20 a month, and Maximum at $100 a month. Ember is a developer model price, not a consumer plan, and nothing in the gateway pages re-read on November 22 changes the consumer record. The Chrome extension record from November 21 also stands: the extension is live, with 200,000 users and a 4.6 rating on its Chrome Web Store listing at last check. Spaces sharing is still not live. None of those rows is a gateway billing row, and this recheck moves none of them.

Quick answers

Do OpenRouter and Vercel charge Ember's long-context tier?

Neither page states a long-context tier. Both were re-read in full on November 22, 2026 and list only $0.10 input and $0.50 output per million, with $0.004 cache read. Their charge past 200,000 input tokens is not stated on either listing.

What does Meta charge past 200,000 input tokens?

Per Meta's own pricing page, $0.30 input, $1.50 output, and $0.012 cached input per million tokens, applied to the whole request, not only to tokens past 200,000.

Why does Poe list Ember output at $0.51?

No reason is given on Poe's page. Poe re-read on November 22, 2026 still lists text output at $0.51 per million, one cent above Meta, OpenRouter, and Vercel.

Has Oracle published an Ember price?

No Oracle Ember price was found on November 22, 2026. Oracle's own pretrained models list, updated November 11, 2026, contains no Muse model.

What is Ember's base price?

$0.10 input and $0.50 output per million tokens, with $0.004 cached input, for requests up to 200,000 input tokens, per Meta's pricing page.

Frequently Asked Questions

Q: Does a long stored conversation count toward the 200,000 token line on Meta's API?

A: Yes, on Meta's own wording. When a request continues a stored conversation, its input includes that conversation, cached tokens included, and the total input sets the tier.

Q: If a gateway page omits the tier, does that prove the gateway charges the base rate on long requests?

A: No. It proves the model page does not state a tier. The charge could be set in terms, in a dashboard, or on the invoice. Only a stated rate or an actual charge for a request over the line settles it.

Q: Is Poe's $0.51 a typo this site is repeating?

A: The figure was read on Poe's own page on November 16, 2026 and again on November 22, 2026, both times as $0.51 per million for text output, at 17 points per 1,000 tokens. Whether Poe intends the extra cent is not stated on its page.

Q: Where can I read Oracle's Ember price?

A: Nowhere in Oracle's own name that this site could find on November 22, 2026. Oracle's pretrained models document, updated November 11, 2026, lists Llama models under Meta Models and no Muse model at all.

Q: When is the next recheck?

A: December 7, 2026, for all three open rows: gateway long-context billing, Poe's output cent, and an Oracle price.
